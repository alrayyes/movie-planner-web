---
title: Keyboard shortcuts
description: Vim-style navigation on pages long enough to scroll.
---

On any page with enough content to scroll, these shortcuts work the same
way they do in vim:

| Key   | Action             |
| ----- | ------------------ |
| `j`   | Scroll down        |
| `k`   | Scroll up          |
| `gg`  | Jump to the top    |
| `G`   | Jump to the bottom |
| `?`   | Toggle this list   |
| `Esc` | Close this list    |

Press `?` (or the `?` button next to the dark-mode toggle in the header)
any time to see this same list without leaving the page. Shortcuts don't
fire while you're typing in a text field, so they never interfere with
filtering or logging a viewing.
